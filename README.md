> 用**假数据 + 真实业务规则**验证前端功能与项目需求。
> 核心规则（判分、锁定三件套、准确率口径、双重加权抽题、简答自评）按 `4、业务需求（修订初版V1.0）.md`

## 一、快速开始

```bash
cd demo-web
npm install          # 依赖安装（首次）
npm run dev          # 启动开发服务器
```

浏览器打开终端输出的地址（默认 http://localhost:5180 ）。

**无需 MySQL / Redis / JDK** —— Phase 1 的后端语义由浏览器内的 Mock 层承担，数据保存在 localStorage。

### 常用命令

| 命令 | 作用 |
|---|---|
| `npm run dev` | 启动开发服务器 |
| `npm run typecheck` | TypeScript 类型检查（无 lint 环境下的唯一静态保障） |
| `npm run build` | 类型检查 + 生产构建 |
| `npm run smoke` | **服务层冒烟测试**：Node 里对契约面 + Mock 服务层做真实断言（v0.5 的 UM-01~UM-07、PER-01、游客禁写等，共 35 项）。只操作内存替身，不碰浏览器数据 |
| `npm run icons:sync` | 重新生成 ph 图标子集（**新增图标后必须执行**） |
| `npm run icons:check` | 校验图标名与子集是否最新 |
| `npm run release:check` | 本地一键校验（替代 CI，对应技术方案 9.4 节；含类型检查与图标校验） |

## 四、界面结构与设计系统

界面按《8、页面布局设计.md》重构，遵循现代简约 SaaS 后台风格（参考 Notion / Linear），低饱和度、重视长题干阅读体验。

### 4.2 设计令牌（`src/styles/global.css`）

> **V1.3 定为「Material 3 浅色方案（参照 shirone.akatsuki.codes）」**（令牌定案于《16、样式优化.md》§5）：
> 全站颜色由**单一色相参数 `--ql-hue`**（参考站 315，品红/紫调）经 `oklch(L C var(--ql-hue))` 生成，
> **改这一个数字即可整套换色**；派生色（EP 的 `light-N`、阴影、遮罩）用 `color-mix()` 现算，不写死第二套色值。
> Element Plus 用默认浅色主题，不需要暗色主题包。浏览器基线：Chromium 111+ / Safari 15.4+ / Firefox 113+。

| 类别 | 取值（hue=315 解析值） |
|---|---|
| 点缀色（primary） | `#6c2787`；浅底 primary-container `#edd3fa`；其上文字 on-primary `#fff8ff`（对比度 **9.2:1**） |
| 背景 / 卡片 | 基底 surface `#f5eff7`（含细微噪点 + 单一色相柔光，禁止纯平）、卡片 `#fcf9fd`、次级 `#f6f2f8`、下沉 `#efe8f2` |
| 文字层级 | 标题 `#110b13`（18.6:1）、正文 `#3e3343`（11.4:1）、辅助 `#64596a`（6.3:1） |
| 状态色 | 成功 `#006c58`、警告 `#944400`、错误 `#a9000c` |
| 圆角 / 阴影 | 卡片 8px；阴影用标题色 color-mix 现算（卡片 6% / hover 9% / 弹层 14%） |
| 动效 | 弹簧缓动 `cubic-bezier(.22,1.2,.36,1)`（交互 0.18s / 折叠 0.28s），遵循 `prefers-reduced-motion` |
| 间距 / 字号层级 | 8px 栅格（`--ql-s1`~`--ql-s5`）；页面标题 20px > 模块标题 16px > 正文 14px > 辅助 12px |

图标：业务语义图标统一用 **Iconify `ph`**，离线可用（子集生成见 `src/constants/phIcons.ts` + `scripts/icons.mjs`）；
Element Plus 内置图标仅用于其组件内部。相关命令：`npm run icons:sync`（新增图标后重新生成子集）、`npm run icons:check`（校验图标名与子集是否最新，已接入 `release:check`）。

### 4.4 与《8、页面布局设计.md》的逐条对照

| 规范要求 | 实现情况 |
|---|---|
| 风格基调（**V1.3 定案**：Material 3 浅色方案，参照 shirone.akatsuki.codes，理性、沉静、专注、阅读优先） | ✅ 令牌层为 `oklch + --ql-hue` 单一色相参数；未引入深色主题；反模板化观感见《16、样式优化.md》 |
| 色彩规范（primary `#6c2787`、基底 `#f5eff7`/卡片 `#fcf9fd`、文字三级、状态三色） | ✅ 全部以 CSS 变量落地；**页面内零硬编码色值**，派生色统一 color-mix 现算 |

| 面包屑导航必须带上 | ✅ 按路由前缀自动生成「分组 / 页面」 |

## 七、刻意的简化（Phase 1 边界）

| 项 | Phase 1 | Phase 2（真实后端） |
|---|---|---|
| 存储 | 浏览器 localStorage | MySQL 8.4 + Flyway 迁移 |
| 认证 | localStorage 会话（模拟 Redis Session） | Sa-Token + Redis Session |
| 密码 | 演示用哈希函数 | bcrypt |
| AI 判分 | 未实现（决策 D9，v1 本就不做） | v1.5 接入 |
| 批量导入 | 未实现（决策 D8，v1 手工录入） | v1.5 / v2 |

> 页面、store、路由**无需修改**。

## 八、已知环境限制

若在本机沙箱环境（受限模式）中运行，Vite 依赖的 **esbuild 需要创建子进程**，可能被拒绝并报 `spawn EPERM`。
请在**普通终端**中执行 `npm run dev`；本项目自身不依赖任何受限能力。
